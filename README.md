# CAG-170 analysis

This repository contains the datafiles and code used to perform genomic diversity analyses on the uncultured bacterial genus CAG-170.
This analysis was conducted for an MPhil dissertation in Genomic Medicine at the University of Cambridge, 2026.


## Repository contents

**command-line-documentation.md** - the documentation of command-line tools used for genome quality assessment, dereplication, phylogenetic analysis, pangenome analysis, GWAS, and functional annotation. The document lists commands used, with parameters and tool versions noted.

**CAG-170-analysis.Rmd** - the data analysis and visualisation performed in R for phylogenetic diversity, pangenome and accessory genome characterisation, host GWAS, and functional annotation. 

**data/** - the folder containing metadata, phylogenetic trees, gene presence/absence, annotations, and GWAS results produced by command-line tools and used for analysis in R.
